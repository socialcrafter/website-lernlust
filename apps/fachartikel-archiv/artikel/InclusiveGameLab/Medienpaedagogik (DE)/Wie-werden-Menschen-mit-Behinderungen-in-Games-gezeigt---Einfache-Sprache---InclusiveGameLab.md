# Wie werden Menschen mit Behinderungen in Games gezeigt - Einfache Sprache - InclusiveGameLab

**Wie werden Menschen mit Behinderungen in Games gezeigt?**

Stellt euch vor:

Ihr spielt sehr gerne Video-Games.

Aber:

In fast **keinem** Game gibt es eine Spiel-Figur,

die so ist wie ihr.

Jede Spiel-Figur ist anders als ihr.

Das ist schade.

Denn:

Alle Menschen sind unterschiedlich.

Das sollte man auch in Games sehen.

Es macht das Game besser für alle.

Das ist gerecht.

Und es zeigt Respekt.

Es gibt noch einen Vorteil:

Wenn viele Menschen sich im Game wiederfinden,

kaufen vielleicht auch mehr Menschen das Game.

Deshalb ist Vielfalt in Games wichtig.

Für Spieler\*innen der Games.

Und für die Entwickler\*innen der Games.

Heute ist es oft so:

Viele Spiele-Figuren sind oft männlich oder weiblich.

Andere Geschlechter fehlen meistens.

Auch andere Gruppen fehlen oft.

Zum Beispiel:

- Menschen mit anderer Herkunft

- Menschen mit anderer Haut-Farbe

- Menschen mit Behinderungen

Oder sie werden nur als **Klischee** gezeigt.

Das bedeutet:

Die Spiel-Figuren sind sehr übertrieben.

Sie verhalten sich immer gleich.

Oft denkt man dann:\
So sind alle Menschen aus dieser Gruppe.

Aber das stimmt **nicht**.

Jeder Mensch ist anders.

In diesem Text geht es um diese Fragen:

Wie werden Menschen mit Behinderungen in Games gezeigt?

Welche Rolle haben sie in der Geschichte vom Game?

Was wissen wir über dieses Thema?

**Menschen mit Behinderungen werden in Games nicht gezeigt**

Im Jahr 2025 ist es so:

Man sieht fast **keine** Menschen mit Behinderungen in Games.

Das passt **nicht** zur Realität in Deutschland.

Denn:

In Deutschland leben viele Menschen mit Behinderungen.

Fast jeder 10. Mensch hat eine schwere Behinderung.

Wenn Menschen mit Behinderungen in Games fehlen,

dann ist das eine Form von Ausgrenzung:\
Wer **nicht** gezeigt wird,

wird auch oft **nicht** als Teil der Gesellschaft gesehen.

Das ist ein Problem.

Denn:

Menschen mit Behinderungen gehören dazu.

Sie sind ein wichtiger Teil der Gesellschaft.

**Behinderung wird oft als etwas Schlechtes gezeigt**

Manchmal gibt es doch Spiel-Figuren mit Behinderung in Games.

Aber:

Wegen ihrer Behinderung werden diese Spiel-Figuren oft negativ gezeigt.

Sie sind zum Beispiel böse.

Oder sie sind sehr traurig.

Manchmal müssen sie geheilt werden.

Die Heilung ist oft schmerzhaft.

Zum Beispiel im Game **The Surge**:

Am Anfang sitzt die Spiel-Figur im Rollstuhl.

Später bekommt sie ein besonderes Gerät am Körper.

Mit diesem Gerät kann sie wieder laufen.

Wo ist das Problem bei **The Surge**?

Die Spiel-Figur wird **nicht** einfach als Mensch gezeigt.

Sondern vor allem als Mensch mit Behinderung.

Die Behinderung steht immer im Mittelpunkt.

Oft wird Behinderung mit etwas Schlechtem verbunden.

Zum Beispiel im Game **Life is Strange**:

Dort gibt es eine Spiel-Figur im Rollstuhl.

Ihr Leben wird als sehr traurig gezeigt.

Sie bittet sogar darum, sterben zu dürfen.

So entsteht der Eindruck:

Ihre Behinderung bringt nur Schmerzen.

Oder sie ist eine Belastung für andere.

Oder es gibt **keine** Hoffnung.

Auch im Game **Bloodborne** gibt es ein schlechtes Beispiel:\
Dort gibt es Spiel-Figuren im Rollstuhl.

Sie sind Gegner im Game.

Sie wirken unheimlich und gefährlich.

So wird der Rollstuhl mit Angst und Gewalt verbunden.

Das ist ein Problem.

Denn:

Solche Games lassen es so aussehen,

als wäre das alles die Wahrheit.

Aber:\
Das stimmt **nicht**.

Behinderung ist **nichts** Schlimmes.

Menschen mit Behinderungen sind **nicht** böse.

Und:

Man muss **kein** Mitleid mit Menschen mit Behinderungen haben.

Menschen mit Behinderungen möchten ernst genommen werden.

Und wie alle anderen Menschen behandelt werden.

**In Games fehlt echte Vielfalt**

Auffällig ist:\
Behinderungen werden in Games oft **nicht** realistisch gezeigt.

Stattdessen benutzen Entwickler\*innen oft Vorurteile oder falsche Vorstellungen.

Man sieht immer wieder dieselben Arten von Behinderungen.

Zum Beispiel:

Blinde Spiel-Figuren mit übermenschlichen Fähigkeiten.

Im Game **Perception** spielt man eine blinde Spiel-Figur.

Sie benutzt einen Langstock zum Gehen.

Das ist realistisch.

Aber:

Die Spiel-Figur tastet **nicht** mit dem Langstock.

Sie klopft damit.

Damit sie das Echo hört.

Das ist falsch.

Viele Menschen denken dann:

Blinde Menschen haben immer ein besonders gutes Gehör.

Das stimmt **nicht**.

Das ist eine falsche Vorstellung.

Solche Games machen diese falsche Vorstellung noch stärker.

So bleiben Vorurteile in der Welt.

In Games fehlt oft die echte Vielfalt.

Denn:\
Jeder Mensch ist einzigartig.

Mit Behinderung oder ohne Behinderung.

In Games sollte es viele verschiedene Menschen geben.

So wie im echten Leben.

Das ist wichtig.

**Vielfältige Bilder sind gut für alle**

Games beeinflussen, wie wir über die Welt denken.

Manche Menschen treffen im Alltag **keine** Menschen mit Behinderungen.

Dann wissen sie wenig über Menschen mit Behinderungen.

Dann haben sie vielleicht falsche Bilder im Kopf.

Dann haben sie vielleicht Vorurteile.

Games können uns etwas beibringen.

Games können zeigen:\
Wie leben Menschen mit Behinderungen?

Wenn Spiel-Figuren mit Behinderungen vielfältig gezeigt werden,

hilft das gegen Vorurteile.

Wir lernen dann:\
Menschen mit Behinderungen gehören dazu.

Menschen mit Behinderungen sind Menschen wie alle anderen.

Ein Game kann zum Beispiel zeigen:\
So lebt eine Spiel-Figur mit Behinderung.

So arbeitet die Figur.

So löst die Figur Probleme.

Das ist wie bei allen Menschen.

Man kann auch sagen:\
Games fördern **Empathie**.

Empathie heißt:

Ich kann fühlen, wie es anderen geht.

So lernen wir:

Alle Menschen sind verschieden.

Und alle gehören dazu.

**Gesehen werden tut gut**

Viele Menschen mit Behinderungen spielen gerne.

Sie wollen Spiel-Figuren sehen, die so sind wie sie.

Wenn ein Game Menschen mit Behinderungen realistisch zeigt, ist das gut.

Dann fühlen die Menschen sich gesehen.

Dann fühlen sie sich dazugehörig.

Gute Bilder von Menschen mit Behinderungen zeigen ihnen:

Ihr seid willkommen.

Ihr seid wichtig.

**Menschen mit Behinderungen wollen sich in Spiel-Figuren wiedererkennen**

Viele Menschen mögen lieber eine vielseitige Spiel-Figur.

Vielseitig heißt:\
Die Figur hat viele Seiten.

Sie hat Stärken und Schwächen.

Zum Beispiel:

- Die Figur ist lustig

- Die Figur ist traurig

- Die Figur macht Fehler

- Die Figur lernt dazu

Das ist besser als eine Figur mit nur einer Seite.

Solche Figuren zeigen oft nur Klischees.

Klischees sind feste Bilder im Kopf.

Klischees machen Vorurteile stärker.

Menschen mit Behinderungen haben im Alltag

schon oft genug mit Vorurteilen zu tun.

Darum ist es gut, wenn ein Game zeigt:

Spiel-Figuren mit Behinderungen haben viele Seiten.

Spiel-Figuren mit Behinderungen können vieles gut.

Die Behinderung ist nur ein Teil ihres Lebens.

Dann merken Menschen mit Behinderungen:\
Ich werde gesehen.

Ich werde verstanden.

Ich werde ernst genommen.

Das stärkt das **Selbstwert-Gefühl**.

Selbstwert-Gefühl heißt:

Ich fühle mich wertvoll.

Ich bin gut, so wie ich bin.

**Wie können Games Menschen mit Behinderungen gut zeigen?**

1.  **Games erzählen echte Geschichten**

> Spiel-Figuren mit Behinderungen sollen vielseitig sein.\
> Sie sollen mehr sein als ihre Behinderungen.\
> Sie sollen zum Beispiel:

- Ziele haben

- Stärken haben

- Schwächen haben

- Macken haben

Menschen mit Behinderungen sind sehr unterschiedlich.\
Diese Vielfalt soll im Game vorkommen.\
Dann wirkt die Geschichte echt.\
\
Das ist wichtig:\
Wir erzählen Geschichten **mit** Menschen mit Behinderungen.\
Wir erzählen **nicht** Geschichten **über** sie.

2.  **Menschen mit Behinderungen machen mit\**
    Es gibt einen wichtigen Satz aus der **Behindertenrechts-Bewegung**:\
    **Nichts über uns ohne uns!**\
    Das heißt:\
    Man soll **nicht** über Menschen mit Behinderungen entscheiden,\
    ohne sie zu fragen.

Dieser Satz passt auch gut zu Games und Medien.

Denn Menschen mit Behinderungen kennen ihr Leben am besten.

Sie können ihre Geschichten am besten erzählen.

Menschen mit Behinderungen sollen bei Games mitmachen.

> Zum Beispiel als:

- Autor\*innen

- Tester\*innen

- Berater\*innen

- Entwickler\*innen

Dann werden Entscheidungen **nicht** ohne sie getroffen.

Dann werden Geschichten **nicht** ohne sie erzählt.

Dann werden Games **nicht** ohne sie gemacht.

Menschen mit Behinderungen fordern:\
Wir wollen mitmachen.

Wir wollen uns **nicht** immer erklären müssen.

Wir sind Teil der Gaming-Welt.

Wir wollen gesehen werden.

Wir wollen gehört werden.

Einige Games machen das schon.

Ein Beispiel ist die Game-Reihe **Hellblade**.

In den Games geht es um **Psychose**.

Psychose heißt:

Man erlebt die Wirklichkeit anders.

Zum Beispiel:\
Man hört Stimmen, die **nicht** da sind.

Man sieht Dinge, die **nicht** da sind.

Eine Psychose ist eine Erkrankung der Seele.

Die Entwickler\*innen haben viel über Psychosen gelernt.\
Sie haben dafür mit Betroffenen gesprochen.

Sie haben auch mit Fach-Leuten gesprochen.

So wollten sie das Thema gut und respektvoll zeigen.

**Games als Chance für alle Kinder und Jugendlichen**

Beim Spielen lernen wir oft Neues.

Das ist eine Chance.\
Denn wir lernen:\
Menschen sind unterschiedlich.

Und sie leben unterschiedlich.

Wir können auch lernen,

wie Menschen mit Behinderungen leben.

Was wir in Medien oft sehen, kennen wir gut.

Was wir in Medien selten sehen, kennen wir schlecht.

Darum ist es wichtig:\
Menschen mit Behinderungen sollen in Games häufiger vorkommen.

So wie andere Menschen auch.

Das ist eine Chance für weniger Vorurteile.

Denn gute Bilder können Vorurteile abbauen.

Wenn Games verschiedene Menschen zeigen,

ist das eine Chance zum Lernen.

Kinder und Jugendliche lernen:

Es gibt verschiedene Lebens-Weisen.

Und alle sind wichtig.

Das ist auch eine Chance für Teilhabe.

So können alle mitmachen.

Kinder und Jugendliche mit Behinderungen.

Kinder und Jugendliche ohne Behinderungen.

**Beispiele für Games**

**mit guten Bildern über Behinderungen:**

1.  Das Game **Watch Dogs 2**

Das Game zeigt das Thema:

**[[Autismus]]-Spektrum**

[[Autismus]] ist ein griechisches Wort.\
In ihm steckt das Wort:\
Selbst

Damit ist gemeint:

Autist\*innen leben in ihrer eigenen Welt.

Sie leben mit sich selbst.

[[Autismus]] kann bei Menschen sehr unterschiedlich sein.

Darum sagt man Spektrum.

Manchen Menschen merkt man [[Autismus]] stark an.

Anderen Menschen merkt man [[Autismus]] kaum an.

Autist\*innen nehmen Informationen anders auf.

Sie verstehen vieles anders.

Das Game zeigt [[Autismus]] so:

Eine Haupt-Figur heißt Josh Sauchak.

Josh zeigt Merkmale von [[Autismus]].

Zum Beispiel:\
Josh spricht manchmal sehr gleichmäßig.

Manchmal versteht er soziale Situationen **nicht**.

Das Game zeigt diese Merkmale ruhig.

Und als normalen Teil von Josh.

Ohne Klischees.

Das Game macht klar:

Josh ist mehr als seine Diagnose.

Josh sagt selbst:\
Ich mag, wer ich bin.

Ich weiß **nicht**, ob ich mich ohne [[Autismus]] mögen würde.

2.  Das Game **Final Fantasy XV**

Das Game zeigt das Thema:\
Blindheit

Das Game zeigt das Thema so:

Eine wichtige Spiel-Figur heißt Ignis Scientia.

Ignis wird im Game blind.

Trotzdem macht er weiter mit.

Seine Freund\*innen unterstützen ihn.

Sie lernen, wie sie ihm helfen können.

Aber:

Sie haben **kein** Mitleid.

Sie behandeln ihn weiter als Teil der Gruppe.

Ignis sagt klar:

Ich will weiterkämpfen.

Das ist meine Entscheidung.

Er lässt sich **nicht** aus der Gruppe drängen.

Er will selbst bestimmen, was er kann.

Er will selbstständig bleiben.

Dabei zeigt das Game auch:

Es ist **nicht** immer leicht.

Ignis ist manchmal frustriert.

Ignis ist manchmal verletzlich.

Viele Menschen finden:

Das Game zeigt Blindheit gut.

Es gibt **keine** Wunder-Heilung.

Ignis ist **nicht** da,

um andere zu beeindrucken.

3.  Das Game **Marvel's Spider-Man: Miles Morales**

Das Game zeigt das Thema:

Gehörlosigkeit

Das Game zeigt das Thema so:

Eine wichtige Spiel-Figur heißt Hailey Cooper.

Hailey ist gehörlos.

Sie spricht mit Gebärden-Sprache.

Die Sprache heißt:\
**American Sign Language**

Die Abkürzung lautet so:\
**ASL**

Die Gebärden im Game sind richtig gemacht.

Gehörlose Berater\*innen haben geholfen.

Und eine gehörlose Schauspielerin spielt Hailey.

Es gibt Unter-Titel.

Sie helfen beim Verstehen.

Die Gespräche sind respektvoll.

Das Game zeigt:

Haileys Gehörlosigkeit gehört zu ihr.

Und das ist gut so.

4.  Das Game **Apex Legends**

Das Game zeigt das Thema:

Körperliche Behinderung

Das Game zeigt das Thema so:

Eine wichtige Spiel-Figur heißt Octavio Silva.

Octavio verliert bei einem Stunt beide Beine.

Jetzt hat er künstliche Beine.

Man sagt auch:\
**Prothesen**

Das Game geht damit ruhig um.

Manchmal ist es auch lustig.

Aber:

Octavio wird **nicht** lächerlich gemacht.

Die Prothesen sind **keine** Wunder-Heilung.

Sie helfen ihm im Game beim Bewegen.

Die Prothesen sind **nicht** das Wichtigste an ihm.

Wichtiger ist:

- Er ist mutig

- Er liebt Action

- Er geht gerne Risiken ein

Das ist auch gut:\
In dem Game gibt es viele vielseitige Held\*innen.

**Beispiele für Games**

**mit schlechten Bildern über Behinderungen:**

1.  Die Games **Dishonored 2** und **Dishonored: Death of the Outsider**

Die Games zeigen die Themen:

- Seh-Behinderung

- Körperliche Behinderung

Die Games zeigen die Themen so:

Eine wichtige Spiel-Figur heißt Billie Lurk.

In **Dishonored 2** verliert Billie ein Auge und einen Arm.

Aber:

Im Game kann man das rückgängig machen.

Zum Beispiel durch eine Zeitreise.

Dann hat Billie diese Verletzungen **nicht** mehr.

In **Dishonored: Death of the Outsider** sieht man Billie ohne diese Verletzungen.

Später erlebt sie wieder schwere Gewalt.

Dafür bekommt sie übernatürliche Ersatz-Kräfte.

Viele Menschen kritisieren das.

Denn die Games zeigen damit:

Behinderung wird weggemacht.\
Behinderung wird genutzt, um zu schockieren.

So fehlt etwas Wichtiges:

Billie als Person mit Behinderung, die **selbstbestimmt** lebt.

Selbstbestimmt heißt:\
Ich bestimme selbst über mein Leben.

So kann ein falsches Bild entstehen.

Dann wirkt es so:

Behinderung soll weg sein.

Oder Behinderung ist nur da, um zu schockieren.

Aber:\
Das stimmt **nicht**.

Behinderung ist ein Teil vom Leben.

2.  Das Game **Life is Strange**

Das Game zeigt die Themen:

- Körperliche Behinderung

- Depression

Das Game zeigt die Themen so:

Eine wichtige Spiel-Figur heißt Chloe.

Chloe hat **Tetraplegie**.

Das bedeutet:

Chloe kann Arme und Beine **nicht** bewegen.

Sie ist an Armen und Beinen gelähmt.

Im Game wirkt es so:

Chloes Leben ist hoffnungslos.

Chloe ist eine Belastung für andere.

Chloe bittet um Hilfe beim Sterben.

Viele Menschen kritisieren das.

Denn das Game zeigt damit:

Mit Behinderung ist das Leben **nicht** gut.

Aber:

Das stimmt **nicht**.

Auch mit Behinderung kann ein Leben gut sein.

Menschen mit Behinderungen haben Wünsche und Ziele.

Sie haben Freund\*innen.

Sie haben Familie.

Sie gehören dazu.

Im Game gibt es noch eine Spiel-Figur.

Die Spiel-Figur heißt Nathan.

Nathan hat Depression.

Das heißt:\
Er ist lange sehr traurig.

Er hat oft **keine** Kraft.

Er fühlt wenig Hoffnung.

Im Game ist Nathan gewalttätig.

Gewalt hat **nichts** mit Depression zu tun.

Viele Menschen kritisieren das.

Denn das Game verbindet Depression mit Gewalt.

So entsteht ein falsches Bild.

Wichtig ist:

Menschen mit Depression sind **nicht** gefährlich.

Sie brauchen Hilfe und Unterstützung.

Und sie können wieder bessere Zeiten erleben.

3.  Das Game **Wolfenstein II: The New Colossus**

Das Game zeigt die Themen:

- Körperliche Behinderung

- Geistige Behinderung

Das Game zeigt die Themen so:

Eine Spiel-Figur heißt Caroline.

Caroline trägt im Kampf ein **Exo-Skelett**.

Exo-Skelett heißt:\
Ein Anzug, der den Körper unterstützt.

Der Anzug hilft beim Bewegen.

Nach dem Kampf stirbt Caroline.

Viele Menschen kritisieren das.

Denn so wirkt es:\
Die Behinderung ist nur für Drama da.

Und die Figur ist schnell wieder weg.

Eine andere Spiel-Figur heißt Max Hass.

Max hat eine geistige Behinderung.

Obwohl er stark ist,

zeigt ihn das Game sehr kindlich.\
Und er kann nur wenig sprechen.

Viele Menschen kritisieren auch das.

Denn das Game zeigt ein Klischee:\
Max ist nur hilfreich für andere.

Er wird **nicht** als eigenständige Person gezeigt.

4.  Das Game **The Quiet Man**

Das Game zeigt das Thema:

Gehörlosigkeit

Viele Menschen kritisieren das Game.

Denn das Game nutzt Gehörlosigkeit nur als **Gimmick**.

Gimmick heißt:

Ein besonderer Effekt im Game.

Der Effekt soll spannend wirken.

Aber:

Das Game zeigt Gehörlosigkeit **nicht** wirklich.

Das ist auch schlecht:

Es gibt oft **keine** Unter-Titel im Game.

Oder die Unter-Titel sind schlecht gemacht.

Viele Dinge sind im Game **nicht** einheitlich.

Das Game zeigt wenig über das Leben von gehörlosen Menschen.

Und es ist schlecht zu spielen.
