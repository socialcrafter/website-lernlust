# Barrieren in Games - Einfache Sprache - InclusiveGameLab

**Barrieren in Games**

**Was ist eine Barriere?**

Eine Barriere ist ein Hindernis.

Hindernisse versperren den Weg.

Dann kommt man **nicht** mehr weiter.

Hindernisse sind zum Beispiel:

- Treppen

- Kleine Schrift

- Schwere Sprache

Barrieren gibt es auch in Games.

Barrieren in Games führen dazu:

Viele Menschen können **nicht** mitspielen.

**Welche Barrieren gibt es in Games?**

1.  **Sehen oder Hören ist notwendig**

In vielen Games muss man gut sehen können.

In vielen Games muss man gut hören können.

Diese Sinne sind bei Menschen unterschiedlich stark.

Manche Menschen können schlecht hören oder sehen.

Manche Menschen können **gar nicht** hören oder sehen.

Dann fehlen wichtige Infos im Game.

Damit alle Menschen mitspielen können:

Man kann Sachen im Game auf verschiedene Arten zeigen.

Man kann die Sachen mit Geräuschen zeigen.

Und man kann die Sachen gleichzeitig mit Bildern zeigen.

Zum Beispiel:\
Ein Gegner kommt von hinten.

Man hört Schritte.

Man sieht dazu Unter-Titel auf dem Bild-Schirm.

Oder einen Pfeil.

Wenn es im Game etwas zu hören **und** zu sehen gibt:

So erkennen auch Menschen mit Beeinträchtigungen die Gefahr.

2.  **Unter-Titel sind schlecht gestaltet**

In vielen Games gibt es Unter-Titel.

Unter-Titel sind Texte auf dem Bild-Schirm.

Sie zeigen gesprochene Worte.

Und sie zeigen Umgebungs-Geräusche.

Doch leider sind die Unter-Titel **nicht** immer gut.

Sie sind manchmal schwer zu lesen.

Gute Unter-Titel sind so:

- Die Schrift ist groß

- Die Schrift ist deutlich

- Die Schrift ist ohne Verzierungen

- Man kann die Schrift-Größe einstellen

- Man kann die Farben einstellen

Unter-Titel sollten das zeigen:

- Welche Spiel-Figur spricht

- Welchen Gefühls-Ausdruck die Spiel-Figur hat

- Von wo die Stimme kommt

- Verschiedene Ton-Signale

Ton-Signale sind zum Beispiel Umgebungs-Geräusche

3.  **Die Steuerung kann nicht geändert werden**

Manche Menschen können nur mit einer Hand spielen.

Oder sie spielen mit anderen Körper-Teilen.

Es gibt verschiedene Arten zu spielen.

Es gibt verschiedene Arten zu steuern.

Damit alle Menschen mitspielen können:

- Man sollte die Tasten-Belegung im Game ändern können

Das bedeutet:\
Jede Taste bekommt eine andere Funktion

- Man sollte spezielle Steuer-Geräte anschließen können

Spezielle Steuer-Geräte sind gut für Menschen mit Beeinträchtigungen

4.  **Keine Pause-Funktion**

Die Pause-Funktion ist sehr wichtig.

Wenn es im Game **keine** Pausen gibt:

Manche Menschen sind überreizt.

Wenn sie überreizt sind:

Sie fühlen sich gestresst.

Oder sie fühlen sich erschöpft.

Manche Menschen bekommen Schmerzen.

Zum Beispiel:\
Ihre Finger tun weh, weil sie zu lange spielen.

5.  **Speichern geht nur automatisch**

Manche Games speichern die Fortschritte nur automatisch.

Dann kann man die Fortschritte **nicht** selbst speichern.

Die automatische Speicher-Funktion heißt **Autosaves**.

Autosaves passieren an bestimmten Stellen.

Zum Beispiel nach einem Level.

Oder nach einer Aufgabe.

Wenn es im Game nur Autosave gibt:

Manche Menschen spielen zu lange.

Weil sie ihren Spiel-Fortschritt **nicht** verlieren wollen:

Sie spielen länger, als sie wollen.

Sie spielen länger, als es ihnen gut tut.

Wenn sie zu lange spielen:

- Sie sind müde

- Sie bekommen Schmerzen

Besser ist das:\
Man kann **selbst** speichern.

Zu jeder Zeit.

Damit alle Menschen mitspielen können:

Speicher-Punkte sollten zeigen, wo man im Game ist.

Speicher-Punkte können es mit einem Bild zeigen.

Oder mit der Spiel-Zeit.

Oder mit einer Beschreibung.

Speicher-Punkte helfen Menschen, die lange Spiel-Pausen machen.

Speicher-Punkte helfen Menschen, die vergesslich sind.

Speicher-Punkte helfen Menschen, die unkonzentriert sind.

6.  **Quick Time Events sind schwer**

**Quick Time Events** ist ein englischer Begriff.

So spricht man ihn aus:

Kwik Taim Iwents

Es bedeutet übersetzt:

Schnelles Zeit-Ereignis

Quick Time Events funktionieren so:\
Das Game zeigt eine Taste an.\
Man muss die Taste schnell drücken.\
Man muss die Taste ganz oft drücken.\
Sonst verliert man das Game.

Das ist für viele Menschen schwierig.\
Weil sie **nicht** so schnell oder oft drücken können.

Dann macht das Spielen **keinen** Spaß.

Damit **alle** Menschen mitspielen können:

Man kann Quick Time Events weglassen.

Manche Games bieten Alternativen an.

Zum Beispiel:

- Man kann Quick Time Events ausschalten

- Man kann sie automatisch ablaufen lassen

- Tasten können einmal oder länger gedrückt werden statt oft und schnell

- Man kann sich mehr Zeit für Reaktionen lassen

- Man kann sich mehr Zeit für das Spiel lassen

7.  **Games können krank machen**

Manche Games können Menschen krank machen.

Das passiert durch Licht oder Bewegung im Game.

Es gibt Auslöser für Licht-Empfindlichkeit.

Es gibt Auslöser für Bewegungs-Krankheiten.

1.  Manche Games haben starke Licht-Effekte.

Zum Beispiel:

- Schnell wechselndes Licht

- Flackerndes Licht

Diese Licht-Effekte können bei manchen Menschen das auslösen:

- Kopfschmerzen

- Schwindel

- Epileptischer Anfall

Ein epileptischer Anfall ist gefährlich.

Wenn man einen epileptischen Anfall hat:

Dann arbeitet das Gehirn für eine kurze Zeit **nicht** richtig.

Man fällt um.

Wenn Menschen empfindlich auf Licht reagieren,

nennt man das Licht-Empfindlichkeit.

Ein schweres Wort dafür ist:

**Photo-Sensitivität**

2.  Manche Games haben starke Bewegungs-Effekte.

Bewegungs-Effekte entstehen so:

Im Game gibt es Bewegung.

Man läuft, springt oder fliegt im Game.

Aber:

Im echten Leben sitzt man still.

Oder man liegt still.

Das Gehirn bekommt verschiedene Signale über Bewegung.

Die Signale widersprechen sich:\
Es gibt Bewegung im Spiel.

Aber es gibt **keine** Bewegung im echten Leben.

Manche Menschen bekommen davon:

- Übelkeit

- Schwindel

Wenn Menschen empfindlich auf Bewegungs-Effekte reagieren,

nennt man das Bewegungs-Krankheit.

Ein schweres Wort dafür ist:

**Motion Sickness**

Wenn Games Beschwerden auslösen:\
Für manche Menschen sind diese Games gefährlich.

Manche Menschen können ohnmächtig werden.

Und sie können dabei stürzen.

Damit alle Menschen mitspielen können:

- Games sollten **keine** starken Licht-Effekte haben

- Games sollten vor Beschwerden warnen

Welche Licht-Effekte gibt es?\
Welche Bewegungs-Effekte gibt es?\
An welcher Stelle sind die Effekte?

- Es sollte Warnungen **vor** einzelnen Spiel-Situationen geben\
  Eine allgemeine Warnung am Anfang vom Game reicht **nicht** aus

- Es sollte möglich sein, Warnungen einzuschalten

- Es sollte möglich sein, Warnungen auszuschalten

8.  **Klang kann nicht angepasst werden**

In vielen Games kann man den Klang selbst einstellen.

Dafür gibt es einzelne Regler.

Man kann einzelne Geräusche leiser machen.

Man kann einzelne Geräusche lauter machen.

Zum Beispiel:\
Man kann die Hintergrund-Musik leiser machen.

Man kann die Gespräche lauter machen.

Damit alle Menschen mitspielen können:

Klang-Regler im Game sind wichtig.\
Wofür sind Klang-Regler gut?

Sie helfen Menschen mit Hör-Problemen.

Und sie helfen Menschen, die schnell überreizt sind.

So können sie sich besser konzentrieren.

9.  **Barriere-Einstellungen sind schwer zu finden**

Einstellungen für Barriere-Freiheit sind oft versteckt im Menü.

Bevor man die Einstellungen anpassen kann:\
Man muss sich erst durch komplizierte Menüs klicken.

Das ist ein großes Problem.

Besser ist das:

- Einstellungen sind beim Spiel-Start zu sehen

- Einstellungen erreicht man mit einem Knopfdruck

- Menüs werden vorgelesen

Jetzt seid ihr dran:

Kennt ihr gute Beispiele für Games ohne Barrieren?
