# Games sind für jeden Menschen anders schwer - Einfache Sprache - InclusiveGameLab

**Games sind für jeden Menschen anders schwer**

Games haben Barrieren.

Diese Barrieren machen Games schwer.

Barrieren sind für alle Menschen unterschiedlich.

Aber:

**Nicht** jede Barriere ist für alle Menschen gleich schwer.

Denn:\
Alle Menschen haben unterschiedliche Fähigkeiten.

Manche Menschen können bestimmte Sachen gut.

Manche Menschen können bestimmte Sachen schlecht.

In manchen Games gibt es Schwierigkeits-Stufen.

Oft funktionieren die Schwierigkeits-Stufen **nicht** gut:

Was für manche Menschen leicht ist,

finden andere Menschen schwer.

Und umgekehrt.

**Was macht ein Game schwer?**

Das hängt **nicht** nur von den Fähigkeiten ab.

Diese Sachen sind auch wichtig:

- Hat der Mensch Erfahrungen mit Games?

- Kennt der Mensch die Technik gut?

- Hat der Mensch Beeinträchtigungen?

**Was ist eine Barriere?\**
Eine Barriere ist ein Hindernis.

Hindernisse versperren den Weg.

Dann kommt man **nicht** mehr weiter.

In Games gibt es 2 Arten von Barrieren:

1.  **Es gibt beabsichtigte Barrieren**

Sie gehören zum Game.

Sie werden extra eingebaut.

Sie machen das Game spannend.

Das sind beabsichtigte Barrieren:

- Schwierige Sprünge

- Starke Gegner

- Wenig Leben

- Wenig Zeit

2.  **Es gibt unbeabsichtigte Barrieren**

Sie gehören **nicht** zum Game.

Sie sind **nicht** gewollt.

Sie entstehen, wenn ein Game **nicht** zum Menschen passt.

Das sind unbeabsichtigte Barrieren:

- Der Text ist zu klein

- Die Farben sind schlecht zu sehen

- Die Steuerung ist schwer

- Es gibt **keine** Hilfen im Game

Unbeabsichtigte Barrieren machen ein Game schwer.

Dann können manche Menschen das Game **nicht** spielen.

**Was ist Barriere-Freiheit im Game?**

**Barriere-Freiheit** bedeutet hier:\
Alle Menschen sollen das Game spielen können.

Alle Menschen sollen das Game anpassen können.

Deshalb:

Unbeabsichtigte Barrieren müssen weg.

Manche Menschen denken so:

Barriere-Freiheit macht Games zu leicht.

Barriere-Freiheit macht Games kaputt.

Games müssen schwer sein.

Aber:\
Das stimmt so **nicht**.

Barriere-Freiheit macht Games **nicht** leichter.

Barriere-Freiheit entfernt nur unbeabsichtigte Barrieren.

Die Herausforderungen bleiben im Game.

Mit Barriere-Freiheit:\
Alle Menschen können mitspielen.

Alle Menschen haben die gleichen Chancen.

Alle Menschen können Spaß mit Games haben.

**Jeder Mensch empfindet Schwierigkeit anders**

Ein Game ist **nie** für alle gleich schwer.

Ob ein Game schwer ist, hängt vom Menschen ab.

Damit alle Menschen mitspielen können:

Games sollen sich an die Fähigkeiten der Spieler\*innen anpassen.

Gut eingestellte Schwierigkeits-Stufen helfen.

Das sind gute Beispiele für Games mit Schwierigkeits-Stufen:

- Im Game **Baldur's Gate 3** gibt es eine bestimmte Spiel-Einstellung:

> In der Spiel-Einstellung wird die Geschichte zum Game erzählt

- In dem Game **Star Wars Outlaws** gibt es verschiedene Schwierigkeits-Stufen:

Bei jeder Schwierigkeits-Stufe steht, was sich im Game verändert.

Was machen gute Schwierigkeits-Stufen?

- Sie lassen sich während des Games ändern

- Sie erklären, was sich im Game verändert

- Sie erklären die Aufgaben im Game

- Sie zeigen die Herausforderungen

**Das ist wichtig:**

Games sollten viele Einstellungen zum Anpassen haben.

Dann gibt es weniger unbeabsichtigte Barrieren.

So macht Gaming mehr Spaß!
